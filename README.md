🌿 Pause,  a mindful journaling app
Pause is a simple, calming journaling web app built to help you slow down, reflect, and write without pressure.

This project started as a learning-by-building experiment and will continue to evolve as I learn more about web development.

✨ Features (current)
📝 Write daily journal entries
💾 Save entries using localStorage
🗑️ Delete entries anytime
🧠 Memory panel to revisit past thoughts
👤 Profile menu interaction
📱 Clean, minimal, app-like UI

🛠️ Tech Stack
HTML — structure
CSS — styling & layout
JavaScript — functionality
LocalStorage — data persistence

No frameworks. Just fundamentals.

🧪 Project Status
🟡 In progress
This app is intentionally being improved step-by-step as part of my learning journey.
Upcoming improvements may include:
Better UI animations (more subtle & intentional)
Entry timestamps
Edit entries
Dark mode
Better accessibility
Mobile-first refinements
AI chatbot

🌱 Learning Philosophy
This project is not about perfection,
it’s about learning by building, breaking things, fixing them, and improving one step at a time.
Every version is a checkpoint.
